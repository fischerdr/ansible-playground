# OpenShift Zone Label Updater - Implementation Plan

## Overview

Create Ansible role `roles/ocp_zone_label_updater/` that:
- Discovers vSphere MachineSets in `openshift-machine-api` namespace
- Extracts ESXi cluster name (zone) from MachineSet `resourcePool` path
- Propagates configurable zone label to MachineSets, Machines, and Nodes
- Supports dry-run via `--check` mode
- Retries on 409 conflict errors

**Reference:** `roles/hydra_thin_csi/` (modular orchestrator pattern)

## Phase 2: Preflight and Validation

**Goal:** Verify environment readiness and validate required inputs.

### Task 2.1: Implement preflight.yml

**Sub-tasks:**

1. Assert Ansible version >= 2.12.0
2. Query all MachineSets in namespace
3. Fail if no MachineSets found
4. Filter vSphere MachineSets (where `workspace` is defined)
5. Fail if no vSphere MachineSets found

**Key pattern:**
```yaml
- name: Query MachineSets
  kubernetes.core.k8s_info:
    api_version: "machine.openshift.io/v1beta1"
    kind: MachineSet
    namespace: "{{ ocp_zone_label_updater_namespace }}"
  register: ocp_zone_label_updater_all_machinesets
  changed_when: false

- name: Filter vSphere MachineSets
  ansible.builtin.set_fact:
    ocp_zone_label_updater_vsphere_machinesets: >-
      {{
        ocp_zone_label_updater_all_machinesets.resources
        | selectattr('spec.template.spec.providerSpec.value.workspace', 'defined')
        | list
      }}
```

### Task 2.2: Implement validate.yml

**Sub-tasks:**

1. Assert `ocp_zone_label_updater_namespace` is defined and non-empty

## Phase 3: Execute Zone Label Updates

**Goal:** Extract zones from MachineSet paths and propagate labels to Machinesets, Machines, and Nodes.

### Task 3.1: Implement execute.yml

**Sub-tasks within block/rescue:**

#### A: Build Zone Map
- Initialize empty `ocp_zone_label_updater_zone_map`
- Loop over vSphere MachineSets
- Extract `resourcePool` from `spec.template.spec.providerSpec.value.workspace.resourcePool`
- Parse zone from path: `/datacenter/host/<cluster_name>/Resources` → index 2 after split on `/`
- Skip malformed paths with debug message
- Append `{name, zone, resource_pool}` to zone map
- Fail if zone map is empty

#### B: Update MachineSet Labels
- Loop over zone map
- Patch `spec.template.spec.metadata.labels` with zone label
- Use `state: patched`
- Register results
- Retry with `max_retries` and `delay`
- Use `until` clause for 409 retry pattern

#### C: Discover and Update Machines
- For each MachineSet in zone map, query Machines with label selector
  `machine.openshift.io/cluster-api-machineset=<machineset_name>`
- Filter for Running machines with `spec.nodeRef` defined
- Build `ocp_zone_label_updater_valid_machines` list
- Patch each Machine's `metadata.labels` with zone label
- Set `ocp_zone_label_updater_machines_updated` count

#### D: Update Nodes
- For each valid machine, patch Node `metadata.labels` with zone label
- Set `ocp_zone_label_updater_nodes_updated` count

## Phase 4: Verify and Report

**Goal:** Confirm label propagation and emit operation summary.

### Task 4.1: Implement verify.yml

**Sub-tasks:**

1. Re-query each MachineSet from zone map
2. Assert `ocp_zone_label_updater_label_key` present with expected zone value in `spec.template.spec.metadata.labels`
3. Re-query each Machine from valid_machines list
4. Assert label present on Machine `metadata.labels`
5. Re-query each Node by name
6. Assert label present on Node `metadata.labels`

### Task 4.2: Implement report.yml

**Output format:** Structured summary with:
- Namespace and label key
- MachineSets processed count
- Machines updated count
- Nodes updated count
- Per-MachineSet zone mapping table
